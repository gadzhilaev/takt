# Уведомления

- In-app: assignment, completion, mentions, invites и др.  
- Web Push: VAPID (`push_subscriptions`)  
- Mobile FCM: `device_push_tokens`, регистрация после логина  
- Тексты assignment на русском с учётом рода/падежей (`ru_names`)

API: `/api/v1/notifications`, `/notifications/device-token`.
