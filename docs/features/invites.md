# Участники и приглашения

- Приглашение по email; поиск зарегистрированных пользователей  
- In-app inbox приглашений (`/invites/mine`)  
- SMTP для писем **не имитируется**, если не настроен — приглашение всё равно создаётся в продукте  
- Accept/decline меняет `project_members`

Не создавать фиктивные аккаунты с именами реальных людей вне демо-сидов.
