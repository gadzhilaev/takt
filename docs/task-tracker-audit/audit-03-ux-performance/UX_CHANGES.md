# UX / UI изменения

## Принцип

Критичные действия видны сразу: **создать**, **мои задачи**, **срок**, **исполнитель**, **статус**. Технический жаргон убран из первичных подписей.

## Навигация и оболочка

- Sidebar: подсказки под пунктами («Поручения вам», «Доски по проектам»…).
- Главная кнопка **«Создать задачу»** в сайдбаре и на обзоре.
- «Админка» → **«Пользователи»**.
- Mobile bottom bar: Обзор / Мои / Проекты / Список / Создать (44px+).
- Поиск: «Найти задачу…».

## Темы

- Semantic CSS variables (`--surface`, `--surface-2`, `--border`, `--accent`, …).
- Light: светлый фон, белые карточки, контрастный текст.
- Dark: согласованные поверхности без «чёрных дыр» inputs.
- Task cards / inputs / tables используют tokens, не `bg-slate-950` на light.

## Карточка задачи

- «Описание» вместо «Markdown» в заголовке.
- «Статус (на каком этапе)», «Важность», «Срок выполнения», «Кто выполняет».
- Исполнители — **чекбоксы с именами**, не multi-select.
- Крупные чеклист-чекбоксы.

## Kanban / Обзор / Мои / Список

- Карточки: имена исполнителей, «Без исполнителя», «Просрочено: …», комментарии.
- «Добавить задачу» с формой «Новая задача».
- Обзор: блоки На сегодня / Просроченные / В работе / **Уже выполнены**.
- Мои: понятный subtitle про назначение.
- Список: «Важность», surface-table.

## Отчёты

- Pie «По статусам» с агрегированными именами.
- Bar «Закрыто по дням».
- `% в срок`: `—` если нет закрытых со сроком; иначе доля вовремя.
