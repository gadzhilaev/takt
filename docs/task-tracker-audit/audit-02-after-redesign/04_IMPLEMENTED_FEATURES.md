# 04. Реализованные возможности (подтверждённые)

Только то, что **проверено** API и/или браузером 2026-10-28. Наличие в коде без runtime-проверки сюда не входит.

## Auth и доступ

- Вход admin/member по email+password, JWT cookies, CSRF
- Роль admin видит «Админку»; member получает 403 на admin API
- Профиль в shell (имя/email), logout

## Проекты

- Список проектов с цветом, описанием, progress `done/total/%`
- Default-проект «Общее»
- Sidebar shortcuts на проекты
- Kanban per project с собственными колонками статусов

## Задачи — ядро

- Создание (smoke + demo)
- Просмотр/редактирование на `/tasks/{id}`
- Статус, приоритет, срок, исполнители, метки
- Завершение через статус «Готово» (`closed_at`)
- Перемещение между колонками (API move + UI DnD заявлено; API подтверждён)
- Soft delete / архив / дублирование / копирование ссылки (кнопки на UI)
- Описание Markdown + preview toggle

## Чеклисты, комментарии, история

- Чеклист: отображение, добавление пункта, отмеченные/неотмеченные пункты
- Комментарии: list + compose с подсказкой `@`
- Упоминание создаёт notification у упомянутого (member inbox API)
- Activity «created» на карточке

## Представления

- Обзор: сегодня / просроченные / в работе / на проверке + прогресс проектов
- Мои задачи: группировка по срокам включая завершённые
- Список: таблица со статусом, приоритетом, сроком, исполнителями
- Фильтры на доске: текст, приоритет, исполнитель
- Inbox UI (empty state)

## Отчёты

- Сводные метрики created/closed/in_progress/overdue/avg_days
- Таблица по сотрудникам
- Недавно завершённые
- Скачивание Excel

## Админка

- Список пользователей (role, status, created, last login)
- Форма создания + generate password + «потребовать смену пароля»
- Кнопка отключения
- Ссылка на настройки команды

## Темы

- Светлая / Тёмная / Системная через меню «Тема»

## Демо-контент

- 3 demo-проекта + Общее, задачи активные/готовые/просроченные, labels, assignees, checklist items, комментарии seed
