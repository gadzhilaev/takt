# ADR 0004 — Упрощённый Kanban UI

- **Статус:** принято

## Контекст

Ранние версии содержали dashboard/home, list, report charts. Продуктовая цель — простой Kanban.

## Решение

Основной UI = проекты + доска. Report API может оставаться; web charts и сложные фильтры убраны из продукта. Маршруты `/report` и т.п. редиректят на `/app/projects`.

## Последствия

- Не возвращать отчёты/AI-dashboard паттерны без запроса.  
- Исторические скриншоты с report удалены при уплотнении docs; решение зафиксировано этим ADR.
