# ADR 0005 — Apple Sign In только в mobile

- **Статус:** принято

## Контекст

VK/Яндекс нужны на web и mobile. Apple ожидается магазинами приложений; для web оператора в РФ действуют ограничения 149-ФЗ.

## Решение

Кнопки Apple только в Flutter. Web показывает VK + Яндекс. Серверные флаги и `OAUTH_APPLE_ALLOWED_FOR_RU_OPERATOR` управляют доступностью.

## Последствия

- Документация и админ-тогглы должны различать web/mobile.  
- Включение Apple на web — отдельное решение, не «включить в UI по умолчанию».
