# ADR 0001 — Монорепозиторий и legacy-идентификаторы `track`

- **Статус:** принято  
- **Дата фиксации:** 2026-10-29 (по текущему коду)

## Контекст

Продукт переименован в **Takt**, но Docker volumes, `POSTGRES_USER`/`POSTGRES_DB` и `COMPOSE_PROJECT_NAME` исторически назывались `track`.

## Решение

Сохранить технические идентификаторы (`track`, volume prefixes) для совместимости с существующими данными. Бренд и UI — только Takt.

## Последствия

- В документации нужно явно разделять «продукт Takt» и «технический id track».  
- Переименование volumes без миграции данных приведёт к «пустой» БД.
